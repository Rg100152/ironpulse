STEP 1 - Open a terminal inside this folder
-------------------------------------------------------------------------------
cd /path/to/ironpulse

STEP 2 - Create a virtual environment and install Flask
-------------------------------------------------------------------------------
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

WINDOWS USERS (PowerShell) use these instead:
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

STEP 3 - Fill the database with sample workouts, goals and photos
-------------------------------------------------------------------------------
python3 seed_fitness.py

STEP 4 - Start the server
-------------------------------------------------------------------------------
python3 app.py

STEP 5 - Open in your browser
-------------------------------------------------------------------------------
http://127.0.0.1:5000

Stop the server anytime with:  CTRL + C

WHAT TO TRY IN THE APP
-------------------------------------------------------------------------------
1. Scroll the "Scroll-Driven Transformation" section slowly and watch the
   pinned right-hand image morph Strength -> Cardio -> Transformation.
2. Drag the before/after handle in the Progress Studio.
3. Log a workout, add a goal, upload a progress photo, calculate your BMI/BMR.
4. Refresh the page - everything is saved in database/ironpulse.db.

-------------------------------------------------------------------------------
TROUBLESHOOTING
-------------------------------------------------------------------------------
* Port 5000 busy? Open app.py, change the last line to port=8000, save,
  run python3 app.py again and open http://127.0.0.1:8000
* Empty dashboard? Run: python3 seed_fitness.py
* Windows execution policy error? Run PowerShell as admin once:
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

No phone number is used or displayed anywhere in this project.
